# Project Rules

## The Plan

This project follows 6 phases:

- **Phase 0** — Foundation: repo scaffold, docs, hooks, commit skill
- **Phase 1** — Frontend: Vite + React + TypeScript
- **Phase 2** — Backend: NestJS + MongoDB
- **Phase 3** — Dockerization
- **Phase 4** — Improvement: UI/UX polish, code review, refactoring
- **Phase 5** — Finish: polish and push to GitHub

Current phase is tracked in `.claude/state/current-phase`.

## AI.md

AI.md is a living story. After each prompt:
1. Find the "Outcome — _to be written_" section
2. Replace it with what was done and what I changed
3. Keep it readable — like explaining to another engineer

## Commits

Always use the `/commit` skill:
1. Show the proposed commit message and files
2. Wait for my approval before committing
3. Never add AI attribution (no "Co-Authored-By", no "Claude Code" footer)
